# Realmaxville

Professional architectural design, construction, renovation and building plan services in Lagos, Nigeria.

**[Visit Live Site →](https://realmaxville.com)**

## About

Realmaxville is a next-generation construction company established in 2017, delivering architectural design, construction, and renovation services across Nigeria. We sell architectural designs online — residential, commercial, and mixed-use building plans available worldwide.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Fonts:** Inter + Space Mono
- **Payments:** Dodo Payments (adaptive currency — ₦/USD)

## Getting Started

```bash
cd realmaxville-site
npm install
npm run dev
```
